# 30分teacher preview

Instructor Cohort Packの授業運営を講師が短時間で評価するためのpreviewです。受講実績や導入実績を示すものではありません。

## 0–5分: Evidence model

READMEの6区分を確認し、「操作できた」と「互換性を証明した」を分けます。

## 5–15分: Tシャツ課題の採点

[Tシャツ教材](../garments/t-shirt.md)を題材に、学生提出テンプレートの次の欄だけを埋める想定でレビューします。

- exact software version
- prerequisite
- procedure
- expected result
- ExperimentalObservation

## 15–25分: failureの扱い

次の提出を`PASS / REVISE / NOT_TESTED`で判定します。

1. simulation screenshotはあるがversionがない → `REVISE`
2. Unity import成功、runtime未確認 → runtime gateは`NOT_TESTED`
3. target avatarとpose evidence、runtime確認まである → 該当gateを証拠に基づき判定

## 25–30分: cohort設計確認

講師側で以下を確認します。

- 予定受講人数
- 開催時期
- 4回構成が使えるか
- 利用するsoftware exact version
- asset権利の確認方法
- 提出方法

PoCを開始した場合のみ、観測した人数・提出・完走・継続意向をKPI台帳へ記録します。
